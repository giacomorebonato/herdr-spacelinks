# PR Links Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Auto-add a Space's open PR for its checked-out branch as a spacelink titled with the repo name, refreshed on focus and agent turn end, with an opt-in `gh` shim for instant-at-creation.

**Architecture:** One pure core — resolve the Space's repo dirs from `herdr pane list`, find the branch's open PR via `gh`, add it through the existing `addLink`/`reportTokens` machinery — driven by three triggers: extended `refresh` (`workspace.focused`), a new `sync` subcommand (`pane.agent_status_changed` hook + manual action + shim target), and `shim/gh` which socket-invokes the `sync` action after a successful `gh pr create`. A `prsync.json` debounce keeps GitHub API load sane.

**Tech Stack:** Bun-run TypeScript (`spacelinks.ts`, no build step), `node:test` via `bun test`, POSIX-style bun shim.

**Spec:** `docs/superpowers/specs/2026-11-11-pr-links-design.md`

## Global Constraints

- Bun only — never npm/npx; no build artifacts, no compiled output.
- All untrusted JSON gets a runtime type guard (pane list, gh output, `prsync.json`, event JSON) — repo convention.
- After editing TypeScript: `bun run typecheck` then `bun run test` — both must pass.
- Failures are silent skips (stderr log line at most); sync must never break `refresh` or the shim must never break `gh`.
- Link cap stays 9 via existing `addLink`; title = repo name from origin URL, `.git` stripped.
- Debounce window: `SYNC_DEBOUNCE_MS = 60_000`.
- Tests live in `test/spacelinks.test.js` (node:test API, required source directly).
- Commit style: `feat:`/`test:`/`docs:` conventional, matching existing log.

## Review Focus

1. **Detached HEAD / non-git cwd** → sync silently skips, no crash. Test in Task 3.
2. **gh missing or unauthenticated (non-zero exit)** → silent skip, refresh still republishes. Test in Task 4.
3. **Corrupt or hand-edited `prsync.json`** → treated as no timestamps, sync proceeds. Test in Task 4.
4. **Non-GitHub origin (e.g. gitlab)** → no gh spawn, silent skip. Test in Task 2.
5. **Unexpected pane-list JSON or event-JSON shape** → sync skips (or attempts, gated by debounce), never throws out of the hook. Tests in Tasks 2 and 5.
